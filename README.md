
# SQL Practice & Analytics Exercises (SQL Server)

This repository contains a collection of **SQL-only practice and analytics exercises**, written in
**Microsoft SQL Server**.

The project focuses on querying, filtering, aggregations, subqueries, and analytical logic using
realistic datasets, and is intended to demonstrate **strong SQL fundamentals** for data analysis roles.

---

## Development Environment

All queries in this project were developed in a **remote Microsoft SQL Server environment**,
connected to a dedicated SQL Server instance provided by **Analiza College** as part of a
Data Science training program.

---

## Repository Contents

- `SQL_yarin_sabag_project_1.sql`  
  Contains all SQL queries written for the exercises.

- `Summary exercise #1.docx.pdf`  
  The original exercise instructions, including business questions and requirements.

---

## Topics & Skills Covered

The exercises cover a wide range of SQL concepts, including:

- `SELECT` & `FROM`
- Filtering and sorting (`WHERE`, `ORDER BY`)
- Scalar and conversion functions
- Aggregate functions (`COUNT`, `AVG`, `SUM`)
- Analytic logic
- `UNION`, `UNION ALL`, `INTERSECT`, `EXCEPT`
- Subqueries
- String manipulation
- Date-based filtering

---

## Datasets Used

The queries are executed on multiple tables representing different domains:

### Pokémon Table
- String filtering and transformations
- Sorting and aggregations
- Case manipulation and counts

### Orders Table (`DsOne_orders`)
- Category-based filtering
- Date logic (shipping time, weekdays)
- Text analytics on product names
- Aggregation by city and state
- Complex filtering using subqueries

### Advertising Tables (`data_auto`)
- Cost aggregation by date conditions
- Set operations (`UNION` vs `UNION ALL`)
- Logical reasoning about `INTERSECT` results

---

## Project Purpose

This project was created to:
- Strengthen SQL querying and analytical thinking
- Practice writing clean, readable SQL
- Demonstrate proficiency in SQL Server for data analysis
- Showcase problem-solving using SQL only (no Python or BI tools)

---

## How to Use

1. Open the `.sql` file in **SQL Server Management Studio (SSMS)** or any SQL Server-compatible editor.
2. Connect to a SQL Server instance.
3. Execute queries individually to review logic and results.
